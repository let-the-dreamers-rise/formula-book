How it works

  1. Say it

    Mic or keyboard. The words go to a chooser that picks one of the server's tools.

  2. The server does the maths

    An MCP server, spec 2025-11-25 over Streamable HTTP. Grams, developer, totals and scaling live on the server, not in the chat.

  3. It asks, never guesses

    Two clients called Priya? The server asks which one through MCP elicitation. An unknown client gets a refusal and the next step.

  4. One result, three surfaces

    An MCP Apps card on a screen, the same card on a phone, one spoken sentence on a speaker.

Questions

Does this run on Alexa today?

No. The demo uses a simulated Alexa+ client in the repository, labelled on screen. The MCP server is real. Alexa+ add-on tools are partner-only, so it has not been tested on a real device.

Do I need a smart scale?

No. You say the grams from any scale you already use.

What if it mishears a name?

It never guesses. An unknown client gets a refusal and the next step; two matching clients get a question.

What does it cost?

Free for the first 50 formulas per salon. The paid plan price is a hypothesis and payments are not live.

Is it open source?

Yes, MIT licence. Run it locally with two commands.
